# Documentation - Claude Code Webinaari

## CDN Resources

This static website uses the following CDN resources:

### Vue.js (Progressive UI Framework)
- **Version**: 3.4.21
- **CDN URL**: https://cdnjs.cloudflare.com/ajax/libs/vue/3.4.21/vue.global.prod.min.js
- **Purpose**: Progressive JavaScript framework for building interactive user interfaces
- **Security**: Includes SRI integrity check for secure CDN loading

### Tailwind CSS (Utility-First CSS)
- **CDN URL**: https://cdn.tailwindcss.com
- **Purpose**: Utility-first CSS framework for rapid UI development
- **Security**: Includes crossorigin attribute for secure CDN loading

## Features

- **Responsive Design**: Mobile-first design using Tailwind CSS utilities
- **Interactive UI**: Vue.js powered dynamic content
- **Modern Styling**: Clean and professional appearance with Tailwind CSS
- **GitHub Pages Ready**: Static files ready for deployment

## Usage

Simply open `index.html` in a web browser or deploy to GitHub Pages:

1. Go to repository Settings
2. Navigate to Pages section
3. Select the branch to deploy
4. Save and wait for deployment

The site will be available at: `https://[username].github.io/[repository-name]/`

## Development

No build process required! This is a pure static website that runs directly in the browser.

To make changes:
1. Edit `index.html` for structure
2. Edit `styles.css` for custom styling
3. Edit `scripts.js` for Vue.js application logic
